# Security Policy

## Supported Versions

We release patches for security vulnerabilities for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability, please report it privately to help us protect our ~500 users.

### How to Report

1. **Email**: Send details to [your-security-email@example.com]
2. **Include**:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

### What to Expect

- **Acknowledgment**: Within 48 hours
- **Initial Assessment**: Within 5 business days
- **Status Updates**: Every 7 days until resolved
- **Fix Timeline**: Critical issues within 14 days

### Disclosure Policy

- We will coordinate disclosure with you
- Security advisories will be published after fixes are deployed
- You will be credited unless you prefer to remain anonymous

## Security Best Practices

When contributing:
- Never commit `.env` files or secrets
- Use environment variables for sensitive data
- Keep dependencies up to date
- Follow secure coding practices
- Report suspicious activity immediately

Thank you for helping keep Console and our users safe!
